# affiliate-program-terms

Public mirror of the whole directory of [affiliateprogramterms.com](https://affiliateprogramterms.com).
`README.md` is generated — edit `README.template.md` or the source data, never the README.

```
node generate.mjs        # reads ../affterms/data, rewrites README.md
```

## The one rule

**The mirror carries the whole directory**: every record in `../affterms/data/programs.json`, under CC BY 4.0, as the site has been since 2026-10-27 (no free tier any more). The CSV keeps its old filename so existing links hold. Verify after any regeneration that the row count matches `programs.json`.
